## Decisions taken on your behalf (all reversible)

1. Response field name kept as `dataset_id`, now a 32-character string, so API clients keep working.
2. `/history` in production without `API_KEY` requires `?ids=`; the web UI remembers ids uploaded from that browser (`localStorage`). In development it still lists everything.
3. Compose storage uses named volumes instead of the WIP's `./data` bind mount (C10).
4. Superseded docs moved to `docs/archive/`, none deleted.
5. AbuseIPDB also became opt-in, matching the other providers.
