# Aegis Node — Academic Keywords

The following index of academic keywords and subject classifications defines the research scope of the Aegis Node thesis:

1. **Dataset Security** — Inspection, validation, and threat detection inside structured tabular and document data formats.
2. **Malicious Dataset Attacks** — Exploitation techniques leveraging untrusted CSV, JSON, JSONL, and Parquet data ingestion pipelines.
3. **CSV Formula Injection** — Dynamic Data Exchange (DDE) and formula trigger exploitation (`=`, `+`, `-`, `@`, `|`, `HYPERLINK`) in spreadsheet software.
4. **Cross-Site Scripting (XSS)** — HTML script tag (`<script>`), DOM event handler, and `javascript:` protocol injection within dataset text attributes.
5. **SQL Injection Payloads** — Textual SQL fragment injection (`' OR '1'='1`, `UNION SELECT`) targeted at downstream database ingestion scripts.
6. **Multi-Stage Detection Pipeline** — Hybrid security architectures combining static signature scanning, deterministic rule checking, and LLM reasoning.
7. **Antivirus Integration** — TCP socket protocol streaming (`INSTREAM`) to ClamAV daemon containers.
8. **Large Language Models in Cybersecurity** — Contextual threat analysis, evidence-based reasoning, and risk score synthesis using Gemini 3.6 Flash.
9. **Data Minimization for AI** — Privacy-preserving architectures restricting LLM inputs to compact scanner findings while isolating raw data.
10. **Data Sanitization & Remediation** — Format-aware non-destructive threat neutralization and single-quote formula escaping.
11. **Verification Re-Scan** — Automated post-remediation re-scanning and quantitative threat reduction percentage calculation.
12. **Reproducible Security Benchmarking** — Synthetic evaluation corpora, confusion matrix classification metrics (F1, Precision, Recall, FPR), and scan latency throughput.
