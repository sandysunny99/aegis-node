## 2. Key Modules & Core Files Inventory

### Backend (`backend/`)
- `main.py`: FastAPI application entry point, CORS middleware, router registration, `GET /health` endpoint.
- `config.py`: Environment configuration management (port, database URL, Gemini API key, model selection `gemini-3.6-flash`).
- `database.py`: SQLAlchemy engine setup, session generator `get_db()`, SQLite table initialization.
- `models.py`: Database ORM models (`DatasetRecord`, `ScanReportRecord`, `RemediationRecord`).
- `schemas.py`: Pydantic request/response schemas (`UploadResponse`, `ScanResponse`, `RemediationResponse`, `LlmAnalysisOutput`).
- `services/file_service.py`: Safe file storage, UUID hashing, extension validation, MIME detection, path traversal protection.
- `services/llm_service.py`: Gemini 3.6 Flash SDK integration, system prompt injection defense, Pydantic structured output validation.
- `routers/datasets.py`: `POST /upload`, `GET /{id}/status`, `POST /{id}/scan` endpoints.
- `routers/analysis.py`: `POST /{id}/analyze` LLM analysis endpoint.
- `routers/history.py`: `GET /history` paginated scan audit log endpoint.
- `routers/remediation.py`: `POST /{id}/remediate`, `GET /{id}/remediation`, `GET /{id}/download-sanitized` endpoints.

### Scanner Engine (`scanner/`)
- `engine.py`: Multi-stage scan orchestrator (`run_scan()`), combining ClamAV virus scanning with content rules.
- `content_checker.py`: Static rule inspector for formula (`FORM-001..003`), script (`SCRP-001..003`), SQL (`SQLI-001..002`), and binary (`BIN-001`) threats.
- `clamd_client.py`: ClamAV INSTREAM TCP socket client (port 3310) with 0.5s connection timeout and 5s offline caching.
- `sanitizer.py`: Format-aware deterministic threat sanitizer for CSV, JSON, and Parquet datasets.

### Research Evaluation Framework (`evaluation/`)
- `dataset_generator.py`: Generates 100 synthetic benchmark datasets (clean, formula, script, SQL, mixed) and `ground_truth.json`.
- `metrics.py`: Classification metrics (TP/TN/FP/FN/Accuracy/Precision/Recall/F1/FPR), latency metrics, LLM token metrics, remediation metrics.
- `benchmark_runner.py`: Multi-mode evaluation engine comparing `rule_only`, `clamav_only`, `combined`, `combined_llm`, and remediation engine.
- `report_generator.py`: Converts benchmark outputs into `benchmark_results.csv`, `remediation_results.json`, and `docs/phase-6-evaluation-report.md`.
- `README.md`: Evaluation execution commands and reproducibility instructions.

### Frontend UI (`frontend/`)
- `src/App.jsx`: Main React application layout, view switching (Upload, Scan Results, History).
- `src/api.js`: Axios API client functions connecting to FastAPI backend endpoints.
- `src/components/FileUploader.jsx`: Drag-and-drop file upload component.
- `src/components/ScanResults.jsx`: Findings table, risk score gauge, verdict badges.
- `src/components/AiSummary.jsx`: Gemini LLM analysis summary card with confidence and recommendations.
- `src/components/RemediationCard.jsx`: Before vs. after risk score comparison, threat reduction %, transformation action log table, sanitized artifact download button.
- `src/components/HistoryView.jsx`: Audit history table with pagination.

### Documentation (`docs/`)
- `docs/demo-guide.md`: 10-step M.Tech viva demonstration guide.
- `docs/thesis-evidence.md`: Academic M.Tech thesis validation document with mathematical models and detection rules.
- `docs/research-results-summary.md`: Summary of empirical Phase 6 benchmark results.
- `docs/final-project-status.md`: Phase 1–7 execution log and status report.
- `docs/final-defense-checklist.md`: M.Tech software/security/research checklists and 15 viva defense Q&A pairs.

## 3. Command Reference

### Development Startup
```powershell
# 1. Start ClamAV Daemon (Docker)
docker compose up -d

# 2. Start FastAPI Backend (Port 8000)
cd backend
.venv\Scripts\activate
uvicorn main:app --reload --port 8000

# 3. Start React Frontend (Port 5173)
cd frontend
npm run dev
```

### Quality Verification
```powershell
# Pytest Test Suite (46 tests)
backend\.venv\Scripts\pytest.exe tests/ -v

# Ruff Linter Check
backend\.venv\Scripts\ruff.exe check backend/ scanner/ tests/ evaluation/

# Frontend Production Build
cd frontend; npm run build

# Research Benchmark Runner
python -m evaluation.benchmark_runner
```
