# Agent Workflow (Harness Engineering)
**Reference**: ai-boost/awesome-harness-engineering
**Workflow**:
1. **Plan**: Task decomposition and hypothesis.
2. **Inspect**: Read existing context and code before writing.
3. **Implement**: Minimal, surgical changes.
4. **Test**: Unit and integration tests.
5. **Security Check**: Verify threat boundaries (e.g., no SSRF).
6. **Verify**: Run full suite.
7. **Document**: Update architecture and DECISIONS.md.
8. **Commit**: Clean, descriptive commits.
