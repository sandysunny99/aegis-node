# Research Methodology
## Academic Contribution
Evidence-grounded AI-assisted dataset security analysis with deterministic remediation and post-remediation verification.

## Evaluation Metrics
- Precision, Recall, F1-Score
- False Positive Rate (FPR), False Negative Rate (FNR)
- Latency and Memory overhead
- External API Failure Rate

## Benchmarking Pipeline
Compare isolation layers:
1. Baseline (ClamAV + Heuristics)
2. Aegis + YARA + Normalization
3. Aegis + External Reputation
4. Full Aegis (with LLM Analysis)
