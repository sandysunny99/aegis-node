# OpenViking Assessment
**Repository**: volcengine/OpenViking
**Purpose**: Self-evolving context database unifying agent memory, RAG, and skills.
**License**: AGPL-3.0
**Decision**: REFERENCE ONLY
**Reasoning**: AGPL-3.0 is incompatible with the permissive Aegis Node runtime. The project is too complex (requires vector DBs, etc.) for our lightweight architecture. We will adopt its *concepts* for context organization (hierarchical markdown files) without installing any of its code.
